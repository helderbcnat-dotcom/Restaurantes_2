⚙️ Configurar Banco de Dados

Para usar o Minha Mesa com banco de dados, conecte ao seu projeto Supabase (gratuito).

Como configurar:
1. Acesse supabase.com e crie uma conta gratuita
2. Crie um novo projeto
3. Em Project Settings → API, copie a Project URL e a anon public key
4. No SQL Editor, execute o script abaixo para criar a tabela:

CREATE TABLE pedidos ( id BIGSERIAL PRIMARY KEY, restaurante TEXT NOT NULL, prato TEXT NOT NULL, preco NUMERIC(10,2), nota NUMERIC(3,1), data DATE NOT NULL, comentario TEXT, foto TEXT, nota_fiscal TEXT, criado_em TIMESTAMPTZ DEFAULT NOW() );
